# Simulation Logs (Zenodo)

The complete set of 13 `sim_log_*.json` files referenced by the paper
(total ~256 MB) is archived on Zenodo as a citable dataset. The six largest logs
are hosted on Zenodo only; the seven smaller ones are also mirrored in this
repository for convenience.

**Zenodo DOI:** [10.5281/zenodo.21151214](https://doi.org/10.5281/zenodo.21151214)

**Contents of the Zenodo bundle:**

| File | Size | Description |
|---|---|---|
| `sim_log_diploid_v2_action.json` | 78 MB | Diploid v2 with action pathway |
| `sim_log_mendelian_haploid.json` | 66 MB | Mendelian haploid baseline |
| `sim_log_mendelian_v2_action.json` | 45 MB | Mendelian v2 with action pathway |
| `sim_log_diploid_codominant.json` | 42 MB | Diploid codominant expression |
| `sim_log_mendelian_haploid_run1.json` | 10 MB | Mendelian haploid, second seed |
| `sim_log_llm_synthesis_free_action.json` | 6 MB | LLM synthesis, free action |
| `sim_log_llm_synthesis_predator_bloom_locked.json` | 5 MB | LLM synthesis, predator pressure |
| `sim_log_diploid_codominant_run1.json` | 4 MB | Diploid codominant, second seed |
| `sim_log_llm_synthesis_abundance_locked.json` | 4 MB | LLM synthesis, abundance scenario |
| `sim_log_llm_synthesis_free_epoch_run1.json` | 2 MB | LLM synthesis, free epoch, seed 1 |
| `sim_log_llm_synthesis_free_epoch.json` | 2 MB | LLM synthesis, free epoch, baseline |
| `sim_log_llm_synthesis_free_epoch_run2.json` | 2 MB | LLM synthesis, free epoch, seed 2 |
| `sim_log_llm_synthesis_free_regulated_pop.json` | 2 MB | LLM synthesis, population-regulated |

**Reproducing the logs:** they're generated by the live evolutionary-ecosystem
simulation (`bear/examples/evolutionary_ecosystem/server/app.py` in the BEAR
library repo, not included here). The paper evaluations work from pre-recorded
logs; they are not required to regenerate the numbers in `results/`.
